# PushT 목표 거리별 planning (공개 체크포인트, seed 99). 형식은 queue/scheduler.py 머리말.
# 목표: 검증 데모에서 d 스텝 떨어진 시작–목표 20쌍 (repro/eval/pusht_segment_targets.py, d = 25 가 원래 DINO-WM 평가).
#   먼저 만든다:  for d in 25 50 75 100; do python repro/eval/pusht_segment_targets.py $DINO_WORK/results/pusht_long_horizon/targets_d${d}_n20.pkl $d 20; done
# planner: plan_pusht.yaml 의 MPC-CEM 그대로 (300 샘플, topk 30, 30 opt steps, alpha 1, eval_every 1). 두 가지로 돌린다.
#   h<d/5>: CEM horizon = 목표 거리 (goal_H = d/5; upstream plan.py 가 horizon 과 MPC 실행 길이를 goal_H 로 둔다)
#   h5    : CEM horizon 5 (25 스텝) 로 계획하고 다시 계획한다 (goal_H 5)
# MPC 상한은 env 300 스텝에 맞춘다: max_iter = 300 / (5 * goal_H).
# plan.py 를 repro/eval/plan_dump_actions.py 로 감싸 실행한 행동도 남긴다 (kind cmd). 환경변수는 queue/run_plan.sh 가 주는 것과 같다.
